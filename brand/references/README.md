# Reference intake

Drop source material here, then run `/brand-extract`. Claude reads images directly —
no description needed, just good filenames.

## Folders
| Folder | Put here |
|---|---|
| `logos/` | Existing masjid logo, letterhead, signage photos, old flyers |
| `photography/` | **The building itself** — exterior, interior, mihrab, carpet, tilework, door hardware |
| `inspiration/` | Other brands/mosques/books whose feel you want. Include ones you *dislike* too |
| `typography/` | Type specimens, Arabic calligraphy, Bangla lettering you admire |
| `color/` | Palette screenshots, swatch photos, fabric, paint chips |
| `pattern/` | Geometric motifs, tile, screens (jali), carved wood |

## Naming convention — this matters
`<source>--<what-to-take>.<ext>`

```
building--mihrab-tilework-blue.jpg
inspiration--reject-too-corporate.png
logos--current-letterhead-2019.pdf
```

The `reject-` prefix is important: showing Claude what you *don't* want narrows the space
faster than ten examples of what you do.

## Highest-value references, in order
1. **Photos of the actual building.** The palette should come from materials that already
   exist — the carpet, the brick, the mihrab tile. This is the single biggest lever for a
   brand that feels true rather than generic.
2. Anything with existing equity (current logo, signage people already recognise).
3. Three "yes" inspirations and two "no" inspirations.
