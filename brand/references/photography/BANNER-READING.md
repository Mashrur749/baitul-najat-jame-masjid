## A new naming wrinkle

The volunteer vests read **`BAITUN NAJAT` / `JAME MOSQUE`** — not "Jame Masjid".

So the settled English name is right, but the second half is inconsistent with
`site.json`, which currently says "Baitun Najat Jame Masjid". Both are defensible;
they should not both be in circulation. **Masjid** is the more usual choice for a
Bangladeshi masjid's own English name and matches the Bangla মসজিদ directly — but the
vests are already printed, so this is the committee's call, not mine.
