# Reference extraction — pass 1 & 2

Source: 3rd Seerah Competition 2026 (৩য় সীরাত প্রতিযোগিতা-২৬) campaign — landscape
banner + trifold brochure, produced by Team Seerah for the masjid.

## Pass 1 — What is actually there

### Colour
| Observed | Estimate | Where it appears |
|---|---|---|
| Yellow-green / lime | ~`#A5C332` | Logo ground, sun disc, calendar icon, section-header pills, prize table headers |
| Deep olive | ~`#5E6B2C` | Brochure section bars, contact blocks, footer bands |
| Mid olive | ~`#7E9333` | Masjid name in the banner header, secondary headings |
| Near-black charcoal | ~`#2B2B28` | Display lettering, body text, camel/bird silhouettes |
| Warm cream | ~`#F6F2E7` | Page ground on both pieces |
| Neutral greys | `#8C8C8C` → `#E4E4E4` | Dune illustration only |

**The signature colour is a yellow-green, not a forest green.** This matters: it is
noticeably more distinctive than the deep-green default most masjid material uses, and it
is already in circulation with the congregation. It is equity — keep it.

### Type
- **Display Bangla is custom hand-lettering**, not a typeface. Heavy, condensed, angular
  terminals, with the ৩য় set in a lime disc. No font reproduces this — it must be
  vectorised as an asset, not substituted.
- Body Bangla is a conventional screen face (Hind Siliguri / SolaimanLipi family).
- **Numerals are Bengali** throughout the content — ২২, ২০২৬, ১৪৪৮, ৭০০০. Only phone
  numbers use Latin digits. This is a real convention and must be reproduced.
- Latin appears almost nowhere. English is not the primary language here.

### Composition
- Dense and information-rich. Every area is used; there is no Western-minimal whitespace.
- Rounded pill headers carrying an icon + label (🎁 পুরস্কারসমূহ, 📋 নিয়মাবলী).
- Boxed prize tables, numbered rule lists, QR block, pinned contact block.
- Hijra/Seerah illustration: desert dunes, camel caravan, birds, palm fronds, sun disc,
  mosque line-art watermark.

### Feel
Warm · earthy · celebratory

## Pass 2 — The through-line

### Take
1. **The lime green.** It is the recognisable asset. Everything else is negotiable.
2. **Lime as a *ground*, dark text on top** — never lime as text. That is how both pieces
   already use it, and it is also what the contrast maths requires.
3. **Cream page, never white.** Both pieces agree.
4. **Bangla-first.** Bengali numerals in content. English is optional and secondary.
5. **The pill-header-with-icon device.** It structures dense content well and is already
   familiar to this audience.
6. **Density as a virtue.** These posters are read closely, not glanced at. Do not
   "clean this up" into sparse Western layout — that would read as colder, not better.

### Reject
1. **Desert / camels / palms are event dressing, not brand.** They belong to a Seerah
   and Hijra theme. Reusing them on a prayer-times notice or a donation appeal would be
   nonsense. Keep them available as a *campaign* motif, not a permanent one.
2. **The two greens drift.** Lime and olive are used interchangeably without a rule.
   Fix by assigning each a job.
3. **Mixed numeral systems** beyond the phone-number convention.
4. **The logo is too small and gets lost**, particularly in the banner. It needs a
   defined minimum size and clear space.
5. **No consistent grid** — the banner's prize columns are cramped against the rules
   panel. Not a look to preserve.

### Open question — the name
The logo transliterates **BAYTUN NAZAT JAME MASJID**; this repo and the assumed domain use
**baitul-najat**. Bangla is বায়তুন নাযাত. These are three different romanisations.
Pick one and use it everywhere — it affects the domain, email addresses, and every English
asset. Needs a committee decision.
